replay-dispatch

A Claude Code mod in cdeust/claude-mods

Not a shipped mod: the classifier half of scripts/replay-dispatch.mjs. /replay-classify <requests.jsonl> <answers.jsonl> sends each request through $.model.complete, as zetetic-autopilot's spawn classifier does, and writes each answer. Load it with --plugin-dir for one headless run.

replay-dispatch reaches L2 (writes or runs) and passed claude plugin validate with warnings on Claude Code 2.1.304.

  • Events hooked: 2
  • API methods referenced: 4
  • Access from classified calls: L2, writes or runs: writes files, drives Claude, reads files
  • Static scan, not a runtime test
